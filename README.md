# DVDStyler

This is fork of the DVDStyler SourceForge Repo. DVDStyler does not seem to be well maintained anymore, and is difficult to build (especially on MacOS).

The MacOS port is very neglected. The latest official binary is very old - among other issues, it does not
support high-DPI displays and is not ARM native (it is an Intel build that runs under Rosetta2). By builiding your own version, you can get support for the latest Apple hardware and OS versions.

See [BUILD.md](BUILD.md) for the latest MacOS build instructions. 

You can also veiw the original [README](README) file.
